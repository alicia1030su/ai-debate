# AI Debate v0.1.3

界面文案收尾。功能、数据格式与接口不变。

## 修复

- **控制台不再出现 DSH 字样**：状态页的「DSH 版本」改为「服务版本」；「宿主模型服务」标注为「本构建不提供」并说明用「自己配置」；模型来源说明、状态目录说明里提到宿主 profile 的措辞改为描述本服务自己的数据目录。页签顺序、字段、按钮一个没少——只换了说给用户听的话。
- **状态目录来源显示的是真实路径**：原先会拼一个 `DSH_HOME=` 前缀，现在显示服务实际解析出的目录。
