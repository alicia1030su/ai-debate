# AI Debate v0.1.1

v0.1.0 之后的一轮质量修复。功能与界面不变，验收结论不变。

## 修复

- **同一数据目录只允许一个实例**：第二个 `serve` 会检测到已运行的实例并退出（退出码 3，提示地址），不再出现两个控制台看同一份台账、配置保存一直报冲突的情况。判断依据是「pid 仍存活」且「该端口的 `/healthz` 仍应答」，陈旧的记录会被清掉而不是永久拦截。
- **`npm start` 真正启动服务**：此前 `start` 指向的入口只导出函数、没有模块级调用，命令会「成功退出但什么也没起」。现在 `packages/server/src/main.ts` 是真正的入口，且 `cli.ts` 只在被直接调用时自我执行，`import` 不会误触发。
- **移除前端未校验的 CSRF 头**：页面会发 `x-ai-debate-csrf`，服务端从不校验，读代码的人会以为存在这层控制。写请求的保护本来就是「`SameSite=Strict` + 同源 `Origin`/`Host` + 必须 `application/json`」三层，现在代码与文档一致。
- **静态资源清单只由构建产出**：仓库里不再跟踪会漂移的 `static/manifest.json`；`dist/web/manifest.json` 由打包脚本按实际文件生成。

## 升级

覆盖程序即可，数据目录不变。v0.1.0 与 v0.1.1 的数据格式相同。

## 校验

同一 Release 附带 `SHA256SUMS.txt`。
